# 체험첵! Field-Check!

현장체험학습 · 수학여행, 선생님이 함께 챙기는 체험학습 도우미입니다.
사전 준비부터 당일 인원 점검, 사후 설문과 결과 정리까지 한곳에서 챙겨요.

- 주소: https://musicalpe.github.io/Field-Check/
- 선생님은 구글 계정으로 로그인하고, 학생은 로그인 없이 QR로만 참여해요.

## 할 수 있는 것

| 사전 | 당일 | 사후 |
|---|---|---|
| 출발일 기준 업무 일정표 | 지금 일정과 다음 점검 한눈에 | 로그인 없는 QR 사후 설문 |
| 일정표와 날씨 예보 (학생용 QR) | 정해진 시간 인원 점검 (실시간 번호표) | 별점·고르기·서술 자동 정리 |
| 안전 교육 (영상 90% 시청 확인, 실시 기록) | 모둠별 현장 미션 활동지 | 그래프 보고서 인쇄·PDF, 엑셀 저장 |
| 준비물 체크리스트 (학생·인솔 교사) | | |
| 사전 설문, 모둠 사전 조사 | | |

- 체험학습마다 동료 선생님 초대 (QR·링크), 반별 보기
- 자료 공유하기: 체험학습 틀을 주소 하나로 다른 선생님께 (학생 기록은 넘어가지 않음)
- 장소 검색(카카오)과 날씨 예보 자동 연결
- 사전 안내 자료, 결과 보고서 (인쇄·PDF)
- AI 도우미 (선택): 활동지 질문·현장 미션, 학부모 안내문, 장소 맞춤 안전 수칙, 서술형 주제별 정리, 성과·개선점 초안
- 홈 화면에 앱으로 설치 (PWA)

## 준비 (직접 운영할 때)

- 파이어베이스 설정: `설정_안내.txt`, 보안 규칙 `파이어베이스_규칙.txt`
- 카카오 장소 검색 키: `kakao-config.js`
- AI 도우미: 파이어베이스 AI Logic과 App Check 사이트 키 (`설정_안내.txt` 5단계, `config.js`)
